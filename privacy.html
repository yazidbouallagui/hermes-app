Privacy policy

Last updated: 23 November 2026

Hermes is a personal tool used only by its owner, Yazid Bouallagui (yazidbouallagui@gmail.com). It is not available to other users.

Data accessed

  • Gmail: messages are read to produce summaries and alerts for the owner; emails are sent only on the owner's explicit request.
  • Google Calendar: events are read (and created only on the owner's request) for reminders and daily briefings.
  • YouTube: videos are uploaded to and managed on the owner's own channels; channel statistics and comments are read for reports.

Storage and sharing

OAuth tokens are stored encrypted-at-rest on the owner's private server with restricted file permissions. Data is used only to provide the features above to the owner. No data is sold, shared with third parties, or used for advertising. Content may be processed by the AI model provider used by the assistant solely to perform the owner's requests.

Google API Services User Data Policy

Hermes' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions; stored tokens are then deleted.
